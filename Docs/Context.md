**학교 등록금 낭비 분석 시스템 문서**

---

### **1. 프로젝트 개요**  
**목표**: 수업 시간 내 비학습 활동을 추적해 등록금 낭비액을 계산하는 크로스 플랫폼 도구 개발.  
**범위**:  
- 데스크톱 (Win), 모바일 (Android) 앱  
- 중앙 서버 (PostgreSQL DB + REST API)  

---

### **2. 기술 스택**  
| 분야 | 기술 | 이유 |
|------|-----|-----|
| 클라이언트 | Flutter (Dart) | Win/Android 단일 코드베이스 + Hot Reload |
| 서버 | Node.js/Express | 경량 API 구축 속도 |
| DB | PostgreSQL | 타임라인 병합 최적화 |

---

### **3. 아키텍처**  
![Architecture](diagram.png) *(상상도)*  
1. **클라이언트**: 화면 점유율 감지 → 타임라인 생성 → 서버와 동기화  
2. **서버**: DB 저장 + 교차 플랫폼 타임라인 병합 계산  
3. **DB**: 학생별 등록금/수업 시간 매핑 + 이벤트 로그  

---

### **4. 핵심 기능**  
#### **공통**  
- 수업 시간표 설정 (캘린더 형식)  
- 실시간 딴짓 시간 추적 (Chrome/YouTube 등 실행 감지)  

#### **데스크톱**  
- 백그라운드 실행 모니터링 (Windows API 활용)  
- 수업 종료 후 낭비액 계산 (등록금 × 딴짓 시간 비율)  

#### **모바일**  
- 상주 서비스 모드 (배터리 효율 고려)  
- 화면 온/오프 상태 연계 추적  

#### **서버**  
- 타임라인 병합 알고리즘 (중복 시간 최대값 선택)  
- 주간/월간 통계 생성  

---

### **5. 개발 프로세스**  
1. **MVP 우선순위**: 타임라인 생성/동기화 → 낭비액 계산 → 그래프 시각화  
2. **협업 방식**: Git Flow (dev/main 분기) + GitHub Issues  
3. **검증**: 단위 테스트 (Dart/JS) + 샘플 데이터 기반 E2E 테스트
